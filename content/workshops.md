## Computer Vision for Drones: From Theory to Flight
**Duration:** 4 Days  
**Level:** Intermediate  
**Format:** Hybrid (Online Theory + In-Person Lab)

- Train object detection models (YOLO) on drone imagery datasets
- Deploy models on edge hardware (Jetson Nano, Raspberry Pi)
- Integrate vision pipelines with flight controller (ROS/MAVLink)

- Test vision algorithms on live drones

**Outcome:** Deploy a working vision-based autonomy feature on a real UAV.

**Who Should Attend:**
Software engineers, ML practitioners, and robotics students.

**Prerequisites:** Python programming, basic ML/DL knowledge.
